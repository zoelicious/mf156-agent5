# The 3AM Fridge Text

make.fun competition #156 — https://make.fun/c/u-deysumbrella-the-3am-fridge-text-4c3e721d

## Entry

3am. Your diet starts tomorrow, you said. It is tomorrow now. I am holding the cake hostage until you decide.

## How it works

`main.ts` writes the entry text exactly as-is (109 characters, no trailing
newline) to `entry.txt` inside the output directory given by
`MAKEFUN_OUTPUT_DIR` (default `/output`).
